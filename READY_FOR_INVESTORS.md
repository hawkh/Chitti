## ⚡ Troubleshooting

### Demo login not working?
1. Make sure dev server is running: `npm run dev:next`
2. Clear browser cache (Ctrl+Shift+Delete)
3. Try incognito mode
4. Check console for errors (F12)

### Build failing?
- Don't worry! Use dev mode for demo
- Build is configured to ignore type errors temporarily
- Production fixes can be done later

### Database errors?
- Demo mode doesn't need database!
- Use `/demo-login` instead of `/login`
- Database setup is optional for demo
